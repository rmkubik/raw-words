# 10/31/26
- https://kevinlynagh.com/newsletter/2026_10_29_llm_programming_and_theory_building/

This is a super interesting post and Kevin is really accurately describing all my frustrations of working with LLMs I've been running into lately. He references the [[Theory building view of programming]].

The core notion here is that, I just don't seem to be successfully able to build a theory of my work when I let the LLM generate code without me.

Kevin outlines a particular strategy he's curious about exploring where you outline code and data models instead of markdown files. That does sound interesting to explore.

But, I think another option is just giving up on having a theory in the first place. That seems totally counter to all my values of being a good software engineer... But it does seem like you need to do that in order to let LLMs generate code for you "at speed".

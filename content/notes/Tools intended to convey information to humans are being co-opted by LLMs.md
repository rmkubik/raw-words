# 10/28/26
I feel like I'm hitting this problem from all angles. But things like this test suite that were intended to convey information to humans are being co-opted by LLMs. Test suites, Pull requests, Ticket descriptions, GitHub comments, product requirement descriptions and everything else. 

The LLMs do seem to benefit from this context. But, now as a human who also wants this context, I can't find it any longer. Every one of these channels is filled with largely unintelligible AI authored text intended for a different AI to glean context from.

I want human-to-human communication channels for all these places that we're filling with AI text. I want to understand when a human has chosen to write text for me, a human to read. I want to know where a human has put thought and effort into something so I can understand it was important. Then, I'll put effort into engaging with it as well.

# 5/19/26
I am curious what less general purpose tools that can help with this problem might look like. I do kind of feel like trying to fight for order is a losing game in a chaotic team environment.

I generally believe, that you should try to make the easy path the thing that leads to the outcomes you want. It is not easy to sit and think long and hard about where to put the code that you want to write or modify.

I wonder if instead, the answer to these problems lies on the other end. Better tools for managing and sifting through the chaos. Accept that hierarchical files is a pretty arbitrary classification for code and never going to really usefully reflect reality.

# 5/18/26
I have always found understanding where TF anything is in my work code bases to be a total crapshoot. I have been bad at the work, slow at figuring it out, and it rarely seems to stick in my head. On smaller projects or features I've had success. In larger teams I've also had success when we took time to actually discuss and align on strategies. In smaller teams and companies it has mostly just been a mess. As I care less about the work, I'm finding myself heavily relying on AI tools for figuring out where stuff is and where it should go.

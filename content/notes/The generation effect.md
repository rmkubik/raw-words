# 10/29/26
This is a psychology idea where "generating" something is going to help you learn it better than attempting to just read it. A list of words is the common example. You'll have worse recall if you read a list than if you omit some words from a list and fill in the missing ones.

This is interesting, because I feel like it is another angle of supporting some of my concerns about AI-driven development. I feel like it is supportive of the [[Theory building view of programming]].
